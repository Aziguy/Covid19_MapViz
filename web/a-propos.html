Le projet

À propos

Covid19 MapViz est né d'une carte Folium des données du 1er avril 2020. Il est devenu un package Python testé et un tableau de bord web ouvert, alimenté par une API publique.

Visualiser

Cartes interactives à l'échelle mondiale, une bulle par pays, proportionnelle à l'indicateur choisi.

Comprendre

Séries temporelles, moyennes mobiles, létalité et incidence rapportée à la population.

Réutiliser

Package Python covid_mapviz avec CLI, tests et couverture, sous licence MIT.

Objectif

Afficher, pour chaque pays, le nombre de personnes infectées, de décès, de guérisons et la part de cas encore actifs, afin de comparer la situation sanitaire entre pays et dans le temps.

Sources de données

  • API publique disease.sh : endpoint /v3/covid-19/countries (cumuls par pays, d'après Worldometers) et /v3/covid-19/historical (séries quotidiennes du JHU CSSE).
  • Archive du 1er avril 2020 : jeu de données d'origine du projet (191 pays), embarqué dans le package et toujours disponible hors ligne.
  • Fond de carte : Natural Earth via world-atlas.

Résilience

Le tableau de bord interroge l'API en direct depuis le navigateur. En cas d'échec, il bascule sur un instantané généré à chaque déploiement GitHub Pages, puis sur l'archive 2020. L'état courant est indiqué en haut à droite de chaque page.

Méthodologie

  • Cas actifs = cas confirmés − décès − guérisons.
  • Létalité observée = décès / cas confirmés. Elle dépend fortement du volume de tests et n'est pas un taux de mortalité de l'infection.
  • Nouveaux cas quotidiens = différence entre deux cumuls successifs ; les corrections négatives sont ramenées à zéro.
  • Moyenne mobile 7 jours : lisse les effets de déclaration du week-end.
  • Surface des bulles proportionnelle à la valeur (rayon en racine carrée), pour ne pas exagérer les écarts.
  • Sunburst et Sankey : angle ou épaisseur proportionnels aux cas ; les pays hors du classement sont regroupés dans « Autres ».

Limites

Le JHU CSSE a cessé sa collecte le 10 mars 2023 et Worldometers son suivi en avril 2024 : les valeurs exposées par l'API sont les derniers cumuls publiés. Le nombre de guérisons n'est plus suivi par de nombreux pays depuis août 2021. Les politiques de dépistage diffèrent fortement d'un pays à l'autre.
