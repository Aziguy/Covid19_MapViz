Générées avec Python

Cartes Folium

Cartes produites par le package covid_mapviz à chaque déploiement : une couche par indicateur, sélectionnable via le contrôle en haut à droite.

Générer une carte en local

pip install -e .
covid-mapviz map --source archive -o output/archive.html
covid-mapviz map --source api -o output/latest.html

Utiliser vos propres données

Tout CSV (UTF-8 ou UTF-16, séparateur détecté) contenant les colonnes Pays, Infections, Deces, Guerisons, Latitudes, Longitudes. 

covid-mapviz map --input mes_donnees.csv -o carte.html
